# Web Development Learning Repository

This repository serves as a practical workspace where I document my progress in full-stack web development. It contains exercises, small projects, and code snippets created while learning both frontend and backend concepts.

---

## Tech Stack & Tools

* **Frontend:** React, JavaScript, HTML, CSS
* **Backend:** Node.js, Express, REST APIs, Databases
* **Tools:** Git, GitHub, Postman, VS Code

---

## Repository Structure

* **Frontend Exercises:** React components, state management, UI implementation, and API integration.
* **Backend Exercises:** Server setup, routing, middleware, REST API creation, and database integration.
* **Mini Projects:** Small full-stack applications connecting client-side interfaces with backend logic.

---

## Goals

* Build a solid understanding of full-stack development principles.
* Practice writing clean, functional, and organized code.
* Maintain a clear record of my technical growth over time.
